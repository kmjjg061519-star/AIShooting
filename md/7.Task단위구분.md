# 역할
너는 10년차 언리얼 게임 개발자야.

# 배경
'기획기본구조.md'에 기획서가 작성돼 있어.

## 요구사항
- '4.기술 명세'의 각 클래스들을 Task 단위로 분리해서 'Task'폴더에 MD 파일로 만들어줘.
- 각 Task의 구현을 제대로 검증하기 위해 체크리스트를 만들어서 'checklists' 폴더에 MD 파일로 만들어줘.
- 한번에 하나의 Task를 구현하고, 언리얼 에디터에서 테스트 하는 방식으로 진행할거야.
    - 예를 들어 Player 이동 > 총알 발사 흐름으로 한번에 하나의 Task가 끝나면 다른 Task를 구현할거야.
- Task에는 구현 순서 번호를 붙여줘.
- 각 등장인물 클래스에서 사용할 StaticMeshComponent를 추가하고 프로토타입에서 사용할 기본 Primitive Date를 할당하도록 해줘.
 - 예를 들어 ' 총알은 StaticMeshComponent를 추가하고 사용할 StaticMesh 데이터는 Cube(크기 100,100,100)를 사용한다.' 처럼 필요한 컴포넌트와 데이터를 할당하도록 해줘.
