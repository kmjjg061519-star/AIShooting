# Task 05. 적 생성 객체 및 추적 AI

## 목표

맵에 수동 배치한 적이 NavMesh 없이 플레이어의 YZ 위치를 추적하게 한다.

## 선행 Task

- Task 04 완료

## 생성 및 변경 대상

- `AAIShootingEnemyPawn : APawn`
- `AAIShootingEnemyAIController : AAIController`
- `BP_AIShootingEnemy` Blueprint

## 구현 범위

1. Enemy Pawn에 충돌 및 외형 컴포넌트를 생성한다.
2. `AIControllerClass`를 `AAIShootingEnemyAIController`로 지정하고 Auto Possess AI를 활성화한다.
3. AIController가 플레이어 Pawn을 찾아 weak pointer로 보관한다.
4. 매 프레임 플레이어 방향에서 X 성분을 제거하고 정규화한다.
5. Enemy Pawn의 `MoveInPlane()`을 호출해 `300 uu/s`로 이동한다.
6. Enemy Pawn은 생성 시 X 좌표를 저장하고 이동 후 복원한다.
7. 플레이어가 없거나 유효하지 않으면 안전하게 이동을 중지한다.
8. NavMesh, Behavior Tree, Blackboard는 사용하지 않는다.

## 컴포넌트 및 Primitive

- `USphereComponent` Root:
  - 반지름 `50 uu`
  - Query Only, Overlap 기반
- `UStaticMeshComponent` Visual:
  - 엔진 기본 Primitive `Sphere`
  - 에셋 경로 `/Engine/BasicShapes/Sphere.Sphere`
  - 원본 지름 `100 uu`
  - Relative Scale `(0.8, 0.8, 0.8)`로 최종 지름 약 `80 uu`
  - 충돌 `NoCollision`
- C++ 생성자에서 기본 Sphere를 할당한다.

## 제외 범위

- 접촉 피해와 사망
- 자동 적 생성
- 경로 탐색과 회피
- 원거리 공격
