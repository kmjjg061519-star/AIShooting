# Task 01. 프로젝트 기반 및 게임 상태

## 목표

Legacy Input 기반 프로젝트 설정과 게임 흐름의 최소 골격을 만든다.

## 선행 Task

- 없음

## 생성 및 변경 대상

- `Source/AIShooting/AIShooting.Build.cs`
- `Config/DefaultInput.ini`
- `Source/AIShooting/Public/AIShootingLog.h`
- `Source/AIShooting/Private/AIShootingLog.cpp`
- `AAIShootingGameModeBase : AGameModeBase`
- `AAIShootingGameState : AGameStateBase`

## 구현 범위

1. `EnhancedInput` 모듈 의존성을 제거한다.
2. `Core`, `CoreUObject`, `Engine`, `InputCore`, `AIModule` 의존성만 사용한다.
3. 기본 입력 클래스를 `/Script/Engine.PlayerInput`, `/Script/Engine.InputComponent`로 설정한다.
4. 다음 Legacy Input 매핑을 정의한다.
   - `MoveHorizontal`: A=-1, D=+1
   - `MoveVertical`: S=-1, W=+1
   - `FireUp`, `FireDown`, `FireLeft`, `FireRight`: 방향키 액션
   - `Restart`: R 액션
5. 프로젝트 로그 카테고리 `LogAIShooting`을 선언하고 정의한다.
6. `AAIShootingGameState`에 `Playing`, `GameOver` 상태와 처치 수 저장 골격을 만든다.
7. `AAIShootingGameModeBase`를 생성하고 `GameStateClass`를 지정한다.
8. 두 클래스의 Tick을 비활성화한다.

## 컴포넌트 및 Primitive

- GameMode와 GameState는 월드 표현용 액터가 아니므로 SceneComponent와 Static Mesh를 추가하지 않는다.

## 제외 범위

- Pawn 및 PlayerController 지정
- 적 생성
- 게임 오버 전환과 재시작 실행
- UI
