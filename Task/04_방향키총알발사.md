# Task 04. 방향키 총알 발사

## 목표

플레이어 이동과 독립된 방향키로 8방향 총알을 반복 발사한다.

## 선행 Task

- Task 03 완료

## 생성 및 변경 대상

- `AAIShootingPlayerProjectile : AActor`
- `AAIShootingPlayerPawn` 발사 기능 확장
- `AAIShootingPlayerController` 발사 액션 확장
- `BP_AIShootingPlayerProjectile` Blueprint

## 구현 범위

1. 네 방향 액션을 `BindAction`의 Pressed와 Released에 각각 바인딩한다.
2. 방향키 상태를 조합해 화면 방향을 월드 YZ 벡터로 변환한다.
3. 상반 입력은 해당 축을 0으로 만들고, 결과가 Zero Vector면 발사하지 않는다.
4. 대각선 발사 벡터를 정규화한다.
5. 키를 누르는 동안 `FireIntervalSeconds=0.2` 간격으로 반복 발사한다.
6. 총알 생성 시 방향을 한 번 전달하고 이후 입력 변경의 영향을 받지 않게 한다.
7. ProjectileMovementComponent의 중력을 0으로 하고 `MoveSpeedUnitsPerSecond=1800`을 적용한다.
8. 총알의 X 속도를 0으로 유지하고 생성 시 X 위치를 고정한다.
9. 카메라 가시 영역과 제거 여백을 벗어나면 총알을 제거한다.

## 컴포넌트 및 Primitive

- `USphereComponent` Root:
  - 반지름 `15 uu`
  - Query Only, 적과 Overlap 예정
- `UStaticMeshComponent` Visual:
  - 엔진 기본 Primitive `Cube`
  - 에셋 경로 `/Engine/BasicShapes/Cube.Cube`
  - 원본 크기 `100×100×100 uu`
  - Relative Scale `(0.2, 0.2, 0.2)`로 최종 표시 크기 `20×20×20 uu`
  - 충돌 `NoCollision`
- `UProjectileMovementComponent`:
  - InitialSpeed와 MaxSpeed `1800`
  - ProjectileGravityScale `0`
- C++ 생성자에서 기본 Cube를 할당한다.
