# Task 06. 전투 충돌 및 생명

## 목표

플레이어, 플레이어 총알, 적 사이의 접촉 피해와 단일 사망 처리를 완성한다.

## 선행 Task

- Task 05 완료

## 생성 및 변경 대상

- `AAIShootingPlayerPawn` HP·피격·사망 확장
- `AAIShootingPlayerProjectile` 적 충돌 확장
- `AAIShootingEnemyPawn` 접촉 공격·사망 확장
- Project Collision 설정

## 구현 범위

1. Player, PlayerProjectile, Enemy용 Object Channel 또는 명확한 Collision Profile을 정의한다.
2. 플레이어 시작 HP를 3으로 설정한다.
3. 적과 플레이어가 Overlap되면 플레이어 HP를 1 감소시킨다.
4. 플레이어와 접촉한 적은 피해 전달 후 즉시 사망한다.
5. 플레이어 총알과 적이 Overlap되면 적과 총알을 제거한다.
6. 요구사항에 따라 플레이어 Pawn과 적이 충돌하면 적도 즉시 사망한다.
7. 각 객체에 `bIsAlive`, `bHasHitTarget` 등의 가드를 두어 중복 처리를 막는다.
8. 사망 처리 시작 시 충돌과 이동을 먼저 비활성화한다.
9. 플레이어 HP가 0이면 입력과 발사를 막되 게임 오버 흐름은 Task 08에서 연결한다.

## 컴포넌트 및 Primitive

- Task 03~05에서 만든 StaticMeshComponent와 Primitive 할당을 유지한다.
- 충돌 판정은 Root의 SphereComponent만 담당한다.
- Visual StaticMeshComponent의 Collision은 모두 `NoCollision`을 유지한다.
