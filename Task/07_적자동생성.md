# Task 07. 적 자동 생성

## 목표

GameMode가 카메라 상단 경계에서 적을 주기적으로 생성하게 한다.

## 선행 Task

- Task 06 완료

## 생성 및 변경 대상

- `AAIShootingGameModeBase` 적 생성 기능 확장
- `BP_AIShootingGameMode` 기본값 설정

## 구현 범위

1. `EnemyClass`, `EnemySpawnIntervalSeconds`, `EnemySpawnMarginUnits`를 EditDefaultsOnly로 노출한다.
2. StartPlay에서 CameraActor와 PlayerPawn을 안전하게 찾는다.
3. Timer로 일정 주기마다 적을 하나 생성한다.
4. 생성 Y는 카메라 가로 가시 범위 안에서 무작위로 선택한다.
5. 생성 Z는 카메라 상단 경계 안쪽 여백 위치를 사용한다.
6. 생성 X는 플레이어의 고정 X와 같게 한다.
7. EnemyClass, CameraActor, PlayerPawn이 없으면 유용한 경고를 남기고 해당 생성을 건너뛴다.
8. Timer를 사용하고 GameMode Tick은 활성화하지 않는다.

## 컴포넌트 및 Primitive

- GameMode에는 컴포넌트와 Mesh를 추가하지 않는다.
- 생성되는 적은 Task 05의 `BP_AIShootingEnemy`와 Sphere Primitive 기본값을 사용한다.

## 제외 범위

- 웨이브와 난이도 증가
- 적 종류 선택
- 오브젝트 풀링
- 보스 생성
