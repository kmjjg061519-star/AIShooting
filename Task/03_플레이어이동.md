# Task 03. 플레이어 이동

## 목표

WASD 입력으로 YZ 평면 안에서만 움직이는 플레이어를 만든다.

## 선행 Task

- Task 02 완료

## 생성 및 변경 대상

- `AAIShootingPlayerPawn : APawn`
- `AAIShootingPlayerController : APlayerController`
- `AAIShootingGameModeBase` 기본 클래스 지정 확장
- `BP_AIShootingPlayer` Blueprint

## 구현 범위

1. Player Pawn에 충돌, 외형, 총알 생성 기준 컴포넌트를 생성한다.
2. PlayerController에서 `BindAxis`로 `MoveHorizontal`, `MoveVertical`을 바인딩한다.
3. 입력 X/Y를 월드 Y/Z 이동 벡터로 변환한다.
4. 대각선 입력 벡터 크기를 1로 제한한다.
5. `MoveSpeedUnitsPerSecond=800`과 DeltaTime으로 이동량을 계산한다.
6. BeginPlay에서 `FixedWorldX`를 저장하고 매 이동 후 X를 복원한다.
7. CameraActor가 제공한 가시 영역 안으로 Y/Z를 제한한다.
8. GameMode의 `DefaultPawnClass`, `PlayerControllerClass`를 지정한다.

## 컴포넌트 및 Primitive

- `USphereComponent` Root:
  - 반지름 `50 uu`
  - Query Only, Overlap 기반
- `UStaticMeshComponent` Visual:
  - 엔진 기본 Primitive `Cone`
  - 에셋 경로 `/Engine/BasicShapes/Cone.Cone`
  - 기본 원본 크기 약 `100×100×100 uu`
  - Relative Scale `(0.7, 0.7, 1.0)`
  - 충돌 `NoCollision`
  - Cone의 뾰족한 방향이 화면 위쪽인 월드 +Z와 일치하도록 배치
- `USceneComponent` ProjectileSpawnOrigin:
  - Visual과 함께 Root에 부착
  - 플레이어 중심을 총알 생성 기준점으로 사용
- C++ 생성자에서 `ConstructorHelpers::FObjectFinder<UStaticMesh>`로 기본 Cone을 할당한다.
- Blueprint에서 다른 Mesh로 교체할 수 있도록 VisualComponent는 읽기 전용 노출한다.
