# Task 08. 게임 오버 및 재시작

## 목표

플레이어 사망부터 게임 정지와 현재 레벨 재시작까지 핵심 루프를 완성한다.

## 선행 Task

- Task 07 완료

## 생성 및 변경 대상

- `AAIShootingGameModeBase` 게임 오버·재시작 확장
- `AAIShootingGameState` 플레이 상태·처치 수 완성
- `AAIShootingPlayerController` Restart 액션 확장
- Player, Enemy, Projectile의 게임 상태 확인 보완

## 구현 범위

1. 플레이어 HP가 0이 되면 GameMode에 사망을 한 번 통지한다.
2. GameMode는 GameState를 `GameOver`로 변경하고 적 생성 Timer를 중지한다.
3. 플레이어 이동과 발사, 적 추적을 중지한다.
4. 남은 총알과 적은 충돌을 중지하거나 제거해 추가 전투 처리를 막는다.
5. `Restart` 액션은 GameOver 상태에서만 동작한다.
6. GameMode의 재시작 함수로 현재 레벨을 다시 로드한다.
7. 재시작 후 HP, 처치 수, Timer, 입력 상태가 초기값으로 돌아온다.
8. 간단한 화면 로그 또는 디버그 표시로 GameOver와 재시작 대기 상태를 확인한다.

## 컴포넌트 및 Primitive

- 새 SceneComponent 또는 Static Mesh를 추가하지 않는다.
- Player Cone, Projectile Cube, Enemy Sphere 기본 Primitive가 재시작 후 동일하게 생성되는지 확인한다.

- 최고 점수 저장
- 페이드 연출과 사운드
