# Task 02. 직교 카메라

## 목표

YZ 플레이 영역을 월드 +X 방향에서 촬영하는 세로형 Orthographic 카메라를 만든다.

## 선행 Task

- Task 01 완료

## 생성 및 변경 대상

- `AAIShootingCameraActor : ACameraActor`
- `BP_AIShootingCamera` Blueprint
- 프로토타입 테스트 맵

## 구현 범위

1. 카메라 위치 기본값을 `(-1500, 0, 0)`으로 설정한다.
2. 회전값을 `(Pitch 0, Yaw 0, Roll 0)`으로 설정해 +X를 바라보게 한다.
3. 상속된 CameraComponent를 Orthographic으로 설정한다.
4. 기준 해상도 1024×2048, 종횡비 0.5를 사용한다.
5. `WorldUnitsPerReferencePixel=2.0`, `OrthoWidth=2048 uu`, 세로 가시 범위 `4096 uu`를 사용한다.
6. YZ 가시 영역의 Half Extent와 위치 Clamp 함수를 제공한다.
7. 카메라 Tick을 비활성화한다.
8. 맵에 `BP_AIShootingCamera`를 배치하고 Player 0의 활성 카메라로 설정한다.

## 컴포넌트 및 Primitive

- 부모 `ACameraActor`의 `UCameraComponent`만 사용한다.
- 촬영 액터이므로 StaticMeshComponent와 Primitive Mesh를 추가하지 않는다.
- 프레이밍 확인용으로 맵에 엔진 기본 Cube를 화면 네 모서리 경계 지점에 임시 배치할 수 있다.

## 제외 범위

- 카메라 이동, 흔들림, 줌
- Perspective 전환
- 플레이어 추적 카메라
