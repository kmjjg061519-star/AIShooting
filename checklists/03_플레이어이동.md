# Checklist 03. 플레이어 이동

## 사전 조건

- [ ] Checklist 02를 통과했다.
- [ ] `BP_AIShootingPlayer`가 현재 GameMode의 Default Pawn이다.

## 컴포넌트 및 Primitive

- [ ] SphereComponent가 Root이고 반지름이 50 uu이다.
- [ ] StaticMeshComponent에 `/Engine/BasicShapes/Cone.Cone`이 기본 할당되어 있다.
- [ ] Cone 원본 약 100×100×100 uu에 Relative Scale `(0.7, 0.7, 1.0)`이 적용된다.
- [ ] Cone이 화면 위쪽 +Z 방향을 향한다.
- [ ] VisualComponent의 Collision이 `NoCollision`이다.
- [ ] ProjectileSpawnOrigin이 Root에 부착되어 있다.

## 입력 및 이동

- [ ] A 입력 시 월드 -Y로만 이동한다.
- [ ] D 입력 시 월드 +Y로만 이동한다.
- [ ] W 입력 시 월드 +Z로만 이동한다.
- [ ] S 입력 시 월드 -Z로만 이동한다.
- [ ] 단일 축 1초 이동 거리가 약 800 uu이다.
- [ ] 대각선 이동 속도가 단일 축 이동 속도를 초과하지 않는다.
- [ ] 이동 시작 전후의 X 좌표가 같다.
- [ ] 플레이어 중심과 Collision 크기를 고려해 화면 경계 안에 제한된다.

## 회귀 확인

- [ ] Orthographic 카메라와 1024×2048 프레이밍이 유지된다.
- [ ] 방향키를 눌러도 현재 단계에서는 플레이어가 움직이지 않는다.
