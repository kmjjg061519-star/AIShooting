# Checklist 07. 적 자동 생성

## 사전 조건

- [ ] Checklist 06을 통과했다.
- [ ] GameMode의 EnemyClass에 `BP_AIShootingEnemy`가 할당되어 있다.

## 생성 설정

- [ ] EnemyClass, Spawn Interval, Spawn Margin이 EditDefaultsOnly로 노출되어 있다.
- [ ] GameMode가 Tick 대신 Timer를 사용한다.
- [ ] 카메라와 플레이어 참조를 안전하게 확인한다.

## PIE 생성 확인

- [ ] 설정한 간격마다 적이 하나씩 생성된다.
- [ ] 생성 Y가 카메라 좌우 가시 범위 안에 있다.
- [ ] 생성 Z가 카메라 상단 경계의 지정 여백 안쪽이다.
- [ ] 생성 X가 플레이어의 고정 X와 같다.
- [ ] 생성된 적이 즉시 플레이어 추적을 시작한다.
- [ ] 여러 적의 Sphere Primitive가 정상 표시된다.
- [ ] EnemyClass가 비어 있을 때 크래시 없이 경고 후 생성을 건너뛴다.

## 회귀 확인

- [ ] 플레이어 이동, 총알 발사, 피해와 적 사망이 유지된다.
- [ ] 화면 밖 또는 잘못된 X 위치에 적이 생성되지 않는다.
