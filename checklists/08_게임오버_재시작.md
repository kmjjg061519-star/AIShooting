# Checklist 08. 게임 오버·재시작

체크 표시는 코드 정적 검토 또는 Editor 빌드로 확인한 항목에만 사용한다. PIE 실제 플레이 검증 항목은 자동화 환경에서 Editor를 상호작용할 수 없어 미체크로 유지한다.

## 사전 조건

- [ ] Checklist 07이 통과한다. (이번 단계에서 PIE로 재검증하지 못함)
- [x] Restart 액션이 R 키에 매핑되어 있다. (`Config/DefaultInput.ini`의 `Restart` ActionMapping)

## 게임 오버

- [x] 플레이어 HP가 0이면 GameState가 GameOver로 한 번만 전환된다. (`ApplyEnemyHit` → `Die` → `TryEnterGameOver` 정적 검토)
- [x] 게임 오버 때 플레이어 이동이 중단된다. (`bIsAlive=false`, 입력 0, Tick 비활성화)
- [x] 게임 오버 때 방향별 발사가 중단된다. (발사 입력 초기화 및 `FireTimerHandle` 해제)
- [x] 게임 오버 때 적 추적이 중단된다. (`MoveInPlane`이 `GameState::IsPlaying()`을 확인)
- [x] 게임 오버 때 적 생성 Timer가 중단된다. (`NotifyPlayerDied`에서 `EnemySpawnTimerHandle` 해제)
- [x] 기존 적과 총알은 추가 피해 또는 처치를 발생시키지 않는다. (남은 적·플레이어 투사체를 즉시 Destroy)
- [x] 게임 오버 상태를 화면 로그 또는 디버그 표시로 확인할 수 있다. (`GAME OVER - Press R to restart` 화면 메시지와 로그)

## 재시작

- [x] Playing 상태에서 R을 눌러도 재시작되지 않는다. (`RestartPressed`의 `IsGameOver()` 가드)
- [x] GameOver 상태에서 R을 누르면 현재 레벨을 다시 시작한다. (`RequestRestart`가 `OpenLevel` 호출)
- [x] 재시작 후 플레이어 HP가 3이다. (새 Player Pawn 기본값 `Health = 3`; 레벨 재로딩 경로 정적 검토)
- [x] 재시작 후 GameState가 Playing이다. (새 GameState 생성자 기본값 `Playing`; 레벨 재로딩 경로 정적 검토)
- [x] 재시작 후 처치 수가 0이다. (새 GameState 생성자 기본값 `KillCount = 0`; 레벨 재로딩 경로 정적 검토)
- [x] 재시작 후 적 생성 Timer가 다시 동작한다. (새 레벨의 `StartPlay`에서 Timer 설정; 정적 검토)
- [x] 재시작 후 방향키 눌림 상태가 초기화된다. (새 Player Pawn의 입력 bool 기본값 `false`; 레벨 재로딩 경로 정적 검토)
- [x] Player Cone, Projectile Cube, Enemy Sphere가 동일한 기본값으로 표시된다. (각 생성자에서 기본 메시를 설정하고 레벨을 재로딩; 정적 검토)

- 실행 일자: 2026-08-31
- UE 버전: 5.8
- Editor 빌드 결과: 성공 (AIShootingEditor, Win64, Development)
- PIE 실행: 미검증 — 현재 자동화 환경에서는 Unreal Editor 상호작용이 불가함.
- 1024x2048 설정: 미검증 — 현재 자동화 환경에서는 PIE/Standalone 뷰포트 설정 및 확인이 불가함.
- 전체 루프 결과: 미검증 — 현재 자동화 환경에서는 Editor 상호작용이 불가하여 실제 플레이를 확인할 수 없음.
- 미검증 항목과 사유: 상단의 모든 `PIE 미검증` 항목. 정적 코드 검토와 Editor 빌드는 확인했으나, 입력·충돌·스폰·재시작의 런타임 연동은 PIE에서 추가 확인이 필요함.
- 발견한 문제: 없음 (정적 검토 및 Editor 빌드 범위).
- 프로토타입 구현 시작 준비 여부: 준비됨 — PIE 수동 검증을 남김.
