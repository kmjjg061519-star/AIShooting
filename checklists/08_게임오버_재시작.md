# Checklist 08. 게임 오버 및 재시작

## 사전 조건

- [ ] Checklist 07을 통과했다.
- [ ] Restart 액션이 R 키에 매핑되어 있다.

## 게임 오버

- [ ] 플레이어 HP가 0이면 GameState가 GameOver로 한 번 전환된다.
- [ ] 게임 오버 후 플레이어 이동이 중지된다.
- [ ] 게임 오버 후 방향키 발사가 중지된다.
- [ ] 게임 오버 후 적 추적이 중지된다.
- [ ] 게임 오버 후 적 생성 Timer가 중지된다.
- [ ] 남은 적과 총알이 추가 피해 또는 처치를 발생시키지 않는다.
- [ ] 게임 오버 상태를 화면 로그 또는 디버그 표시로 확인할 수 있다.

## 재시작

- [ ] Playing 상태에서 R을 눌러도 재시작되지 않는다.
- [ ] GameOver 상태에서 R을 누르면 현재 레벨이 다시 시작된다.
- [ ] 재시작 후 플레이어 HP가 3이다.
- [ ] 재시작 후 GameState가 Playing이다.
- [ ] 재시작 후 처치 수가 0이다.
- [ ] 재시작 후 적 생성 Timer가 다시 동작한다.
- [ ] 재시작 후 방향키 눌림 상태가 초기화된다.
- [ ] Player Cone, Projectile Cube, Enemy Sphere가 동일한 기본값으로 표시된다.

## 전체 핵심 루프

- [ ] 이동한다.
- [ ] 8방향으로 발사한다.
- [ ] 적이 생성되어 플레이어를 추적한다.
- [ ] 총알로 적을 처치한다.
- [ ] 적 접촉으로 HP가 감소한다.
- [ ] HP 0에서 게임 오버된다.
- [ ] R 입력으로 정상 재시작된다.
- [ ] 1024×2048 Orthographic 화면과 YZ 평면 제약이 전체 과정에서 유지된다.
