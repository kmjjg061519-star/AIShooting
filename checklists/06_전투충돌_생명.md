- [x] Root SphereComponent만 게임플레이 Overlap을 생성하도록 구성된 것을 확인하였다.
- [x] 각 Visual StaticMeshComponent의 Collision이 모두 `NoCollision`인 것을 확인하였다.

- [x] 플레이어 총알과 적이 Overlap을 생성한다.

## 피해 및 처치

- [x] 플레이어 시작 HP가 3으로 설정된 것을 확인하였다.
- [x] 적 하나와 접촉했을 때 플레이어 HP가 정확히 1 감소한다.
- [x] 플레이어와 접촉한 적이 즉시 제거된다.
- [x] 총알과 충돌한 적이 즉시 제거된다.
- [x] 적과 충돌한 총알이 즉시 제거된다.
- [ ] 플레이어 Pawn과 직접 충돌한 경우도 즉시 피해를 받는다.
- [x] 하나의 적 또는 총알이 중복 피해와 중복 처치를 발생시키지 않는다.
- [x] HP가 0인 플레이어는 이동과 발사를 하지 않는다.

- [ ] 처치 처리 중 이미 제거된 Actor 접근 오류가 없다.
