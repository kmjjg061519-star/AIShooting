# Checklist 06. 전투 충돌 및 생명

## 사전 조건

- [ ] Checklist 05를 통과했다.
- [ ] Player, PlayerProjectile, Enemy의 Collision Profile을 확인했다.

## 충돌 구성

- [ ] Root SphereComponent만 게임플레이 Overlap을 생성한다.
- [ ] 세 Visual StaticMeshComponent의 Collision이 모두 `NoCollision`이다.
- [ ] 플레이어와 적이 Overlap을 생성한다.
- [ ] 플레이어 총알과 적이 Overlap을 생성한다.
- [ ] 플레이어 총알과 플레이어는 Overlap 처리하지 않는다.

## 피해 및 사망

- [ ] 플레이어 시작 HP가 3이다.
- [ ] 적 하나와 접촉할 때 플레이어 HP가 정확히 1 감소한다.
- [ ] 플레이어와 접촉한 적이 즉시 제거된다.
- [ ] 총알과 충돌한 적이 즉시 제거된다.
- [ ] 적과 충돌한 총알이 즉시 제거된다.
- [ ] 플레이어 Pawn과 직접 충돌한 적도 즉시 사망한다.
- [ ] 하나의 적 또는 총알이 중복 피해와 중복 사망을 발생시키지 않는다.
- [ ] HP가 0인 플레이어는 이동과 발사를 하지 않는다.

## 경계 및 안정성

- [ ] 동시에 여러 Overlap이 발생해도 HP가 음수로 내려가지 않는다.
- [ ] 사망 처리 중 이미 제거된 Actor 접근 오류가 없다.
- [ ] Output Log에 충돌 관련 Error 또는 반복 Warning이 없다.
