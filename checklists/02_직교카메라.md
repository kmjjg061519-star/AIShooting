# Checklist 02. 직교 카메라

## 사전 조건

- [ ] Checklist 01을 통과했다.
- [ ] PIE 뷰포트를 1024×2048로 설정했다.

## 클래스 및 컴포넌트

- [ ] `AAIShootingCameraActor`가 `ACameraActor`를 상속한다.
- [ ] 불필요한 Tick과 추가 컴포넌트가 없다.
- [ ] Projection Mode가 Orthographic이다.
- [ ] Aspect Ratio가 0.5이고 고정되어 있다.
- [ ] Ortho Width가 2048 uu이다.

## 월드 배치

- [ ] 카메라 위치가 `(-1500, 0, 0)`이다.
- [ ] 회전값이 `(0, 0, 0)`이고 월드 +X를 바라본다.
- [ ] 화면 오른쪽이 월드 +Y와 일치한다.
- [ ] 화면 위쪽이 월드 +Z와 일치한다.
- [ ] 2048×4096 uu 가시 영역의 네 경계 표식이 예상 위치에 보인다.

## 기능 확인

- [ ] 가시 영역 Half Extent 계산 결과가 Y=1024, Z=2048 uu이다.
- [ ] Clamp 함수가 X를 바꾸지 않고 Y와 Z만 제한한다.
- [ ] Perspective 왜곡이 보이지 않는다.

## 결과 기록

- 실행 날짜:
- 선행 조건 (Checklist 01): `통과` / `실패` / `미검증` (근거 포함)
- 정적 검증 결과: `통과` / `실패` / `미검증` (소스·에셋 설정 또는 계산 근거)
- 빌드 결과: `통과` / `실패` / `미검증` (실행 명령과 요약)
- 무인 실행 결과: `통과` / `실패` / `미검증` (실행 명령과 로그 근거; GUI/PIE 통과 근거로 사용하지 않음)
- GUI Editor/PIE 결과: `통과` / `실패` / `미검증` (1024×2048, Orthographic 프레이밍, 화면 +Y/+Z 방향, Output Log 확인 근거)

- 경계 Cube 관찰 결과 및 정리 여부:
