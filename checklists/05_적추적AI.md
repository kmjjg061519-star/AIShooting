# Checklist 05. 적 생성 객체 및 추적 AI

## 사전 조건

- [ ] Checklist 04를 통과했다.
- [ ] `BP_AIShootingEnemy`를 카메라 가시 영역 상단에 수동 배치했다.

## 컴포넌트 및 Primitive

- [ ] SphereComponent가 Root이고 반지름이 50 uu이다.
- [ ] StaticMeshComponent에 `/Engine/BasicShapes/Sphere.Sphere`가 기본 할당되어 있다.
- [ ] 원본 지름 100 uu Sphere에 Scale 0.8이 적용되어 지름 약 80 uu로 보인다.
- [ ] Sphere Visual의 Collision이 `NoCollision`이다.
- [ ] EnemyAIControllerClass와 Auto Possess AI가 설정되어 있다.

## 추적 이동

- [ ] 적이 플레이어의 현재 YZ 위치를 향해 이동한다.
- [ ] 적 속도가 약 300 uu/s이다.
- [ ] 적 이동 중 X 좌표가 생성 시점과 같다.
- [ ] 플레이어가 좌우로 움직이면 적의 Y 이동 방향이 갱신된다.
- [ ] 플레이어가 상하로 움직이면 적의 Z 이동 방향이 갱신된다.
- [ ] NavMesh가 없는 맵에서도 추적한다.
- [ ] 플레이어가 없을 때 크래시 없이 정지한다.

## 회귀 확인

- [ ] 플레이어 이동과 8방향 발사가 기존과 동일하게 동작한다.
- [ ] 카메라 프레이밍이 유지된다.
