# Checklist 04. 방향키 총알 발사

## 사전 조건

- [ ] Checklist 03을 통과했다.
- [ ] Player Pawn의 ProjectileClass에 `BP_AIShootingPlayerProjectile`이 할당되어 있다.

## 컴포넌트 및 Primitive

- [ ] SphereComponent가 Root이고 반지름이 15 uu이다.
- [ ] StaticMeshComponent에 `/Engine/BasicShapes/Cube.Cube`가 기본 할당되어 있다.
- [ ] 원본 100×100×100 uu Cube에 Scale 0.2가 적용되어 20×20×20 uu로 보인다.
- [ ] Cube Visual의 Collision이 `NoCollision`이다.
- [ ] ProjectileMovementComponent의 속도가 1800 uu/s이다.
- [ ] ProjectileGravityScale이 0이다.

## 방향별 발사

- [ ] 오른쪽 방향키가 +Y로 발사한다.
- [ ] 왼쪽 방향키가 -Y로 발사한다.
- [ ] 위쪽 방향키가 +Z로 발사한다.
- [ ] 아래쪽 방향키가 -Z로 발사한다.
- [ ] 두 방향키 조합 4종이 각각 올바른 대각선으로 발사한다.
- [ ] 대각선 총알 속도가 단일 방향 총알 속도와 같다.
- [ ] 서로 반대인 방향키만 누르면 총알이 생성되지 않는다.
- [ ] 방향키를 놓으면 총알 생성이 중지된다.
- [ ] 방향키를 누르는 동안 약 0.2초 간격으로 반복 발사한다.

## 독립 입력 및 수명

- [ ] WASD 이동과 방향키 발사를 동시에 할 수 있다.
- [ ] 방향키가 플레이어 이동에 영향을 주지 않는다.
- [ ] WASD가 총알 발사 방향에 영향을 주지 않는다.
- [ ] 생성된 총알은 이후 입력 변경에도 기존 방향을 유지한다.
- [ ] 총알 이동 중 X 좌표가 유지된다.
- [ ] 화면 경계 밖 총알이 제거된다.
